# 📊 Sales Dashboard 2024 - Excel Project

Interactive Sales Dashboard built in Microsoft Excel by Radhika Gundale

## 🔍 Project Overview
Analyzed 100+ rows of sales data to find top performing regions & categories.

## 📈 Key Insights
- 💰 Total Sales: ₹1,53,722
- 🏆 Top Region: South - ₹50,848
- 🏆 Top Category: Technology - ₹73,835
- 📉 Lowest: Central Region (₹26,836)

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Slicers (Interactive Filters)
